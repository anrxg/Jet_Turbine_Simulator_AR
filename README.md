**Jet Turbine AR Simulation

An Augmented Reality (AR) simulation project built in Unity that allows users to interact with a 3D Jet Turbine model in real time.

Project Overview

This project is designed to help users understand the structure and components of a jet turbine through AR visualization. Users can place the turbine model in the real world and interact with different parts of the model using on-screen buttons.

The simulation includes four interactive buttons:

Hull
Tubes
Grip
Piston

Each button allows the user to toggle the visibility of the respective component:

First click → removes/hides the selected part
Second click → brings/shows the selected part again

This helps in better understanding the internal structure and working of the jet turbine.
